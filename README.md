Aushadhi Vault 

AI-Powered Smart Medicine Dispensing System

 About the Project

Aushadhi Vault is a smart medicine dispensing kiosk designed to improve access to medicines in rural and semi-urban areas. It combines prescription scanning, AI-assisted medicine validation, pharmacist verification, and automated dispensing to support safer and more accessible healthcare.

 Objectives

- Improve medicine accessibility in underserved areas.
- Extract prescription information using OCR.
- Support medicine safety checks and flag potential drug interactions.
- Enable pharmacist verification before dispensing.
- Automate medicine dispensing using electronic components.
- Maintain medicine inventory and transaction records.

How It Works

1. User Interaction: The user accesses the kiosk through a touchscreen.
2. Prescription Scanning: A camera captures the prescription.
3. OCR Processing: Prescription text is extracted digitally.
4. AI-Assisted Validation: Medicine details are analyzed and potential safety concerns are flagged.
5. Pharmacist Verification: The prescription is reviewed and approved by an authorized pharmacist.
6. Inventory Check: The system checks medicine availability.
7. Automated Dispensing: A controller operates the dispensing mechanism after authorization.
8. Monitoring and Logging: Sensors help verify dispensing, while the system records relevant transactions.

 Safety Note

Aushadhi Vault is intended to support medicine access, not replace qualified medical professionals. Prescription approval and dispensing must follow applicable medical, pharmaceutical and regulatory requirements. AI-generated outputs must not independently authorize medicine dispensing.
